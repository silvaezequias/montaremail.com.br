# 🚀 Sobre o Projeto

O **MontarEmail** é uma plataforma visual para criação de templates de e-mail modernos utilizando um sistema intuitivo de **arrasta e solta**.

A ideia do projeto é oferecer uma experiência parecida com:

- Webflow
- Wix
- WordPress

porém totalmente focada em:

- e-mails HTML,
- newsletters,
- campanhas,
- onboarding,
- e-mails transacionais,
- componentes reutilizáveis,
- e exportação de código.

# 🎯 Objetivo

O objetivo do MontarEmail é simplificar a criação de e-mails profissionais sem depender de:

- código manual,
- builders complexos,
- ou ferramentas limitadas.

A plataforma busca unir:

- simplicidade visual,
- produtividade,
- flexibilidade,
- e exportação para desenvolvedores.

```bash

# Entre na pasta

# Instale as dependências
npm install

# Rode o projeto
```
